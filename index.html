Things I've built

🛡️

Intelligent Payment Fraud Detection

A deep learning system to detect online payment fraud in real time. Uses a CNN model with ADASYN oversampling and SelectKBest feature selection, plus concept drift adaptation (ADWIN + custom EDDM) so the model stays accurate as fraud patterns evolve. Achieved 100% precision, 93% recall, and 1.0 ROC-AUC. Built as my B.Tech main project.

CineMatch — Movie Recommendation System

A content-based movie recommendation web app supporting English, Hindi, Telugu, and Malayalam cinema. Uses TF-IDF vectorization and cosine similarity over a dataset of ~3,600 movies, enriched live with TMDB and OMDb APIs for cast, crew, OTT availability, trailers, and IMDb ratings. Includes mood-based search, trending movies, favorites/watchlist, and a fully responsive mobile UI.
